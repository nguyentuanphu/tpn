# Field-by-field data and connection register

Generated from `registry.json` by `tools/build.py`. Historical rows preserve their original baseline status and transport/storage contract; they are not relabelled as current code. Current refinements are separately identified. No live database access is implied.

**279 entries:** 137 historical field families plus 142 enumerated current/proposed refinements. Some are overlapping explanations of the same underlying data, not additional collection. This is the management data scope, not every field in a game save.

Each row has a stable ID, source, route, storage, join, permission, destination, connected graphs/controls, privacy, missing-data handling and retention caveat in the [JSON](registry.json) and [CSV](data-connections.csv). Domain-wide graph associations show contextual relevance; each graph’s narrower `data_ids` list identifies its direct historical inputs.

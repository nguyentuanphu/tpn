# Reviewed public voice changes

Each batch freezes fixed public English/Vietnamese lines, their stable speech IDs and SHA-256 hashes of the current TypeScript source. The validator rejects changed sources, unknown text, templates, private names, duplicate entries and family/device sources before contacting either provider.

The recording job uses the shared registry: Azure female/male English and Vietnamese, plus FPT Neo model FPT.AI-VITs voice leminh for Vietnamese. It records missing clips only; never repeats the installed6,663 Lê Minh clips. Original new FPT MP3s and receipts stay under temp/fpt-public-delta; verified32kbps/16kHz/mono delivery copies extend the optional pack. Existing installed clips must match their saved size and digest; corruption is an error before spending provider credit.

For the working-branch review, dispatch the already registered FPT arcade workflow with an inventory input; it calls the generic reviewed-public workflow from the same commit. Without an inventory, the legacy arcade workflow retains its existing behavior. The public workflow is also directly dispatchable once registered on main. Work/release/voices branches only; never main. Shared provider locking prevents simultaneous FPT batches. Results and partial originals are retained even if recording stops; a moved branch refuses an automatic update and leaves a review artifact.

The fragments have different speech IDs from the complete lines and are intentional, not duplicate recordings. New recordings, final audio decode/coverage and human listening are not yet complete. No provider key enters the browser, source, inventory or artifact. Family questions, answers and child names are excluded.

The shared canvas helper fixes these lifecycle/input/save defects while retaining the existing guide compositions and registration names.

The other titles describe themed open-ended painting, not automatic correctness scoring, photo recognition, physical weaving/folding or an educational score. Weave colours a mat guide; mosaic paints cells; lacquer paints gold on the existing illustrated board; gallery paints inside a frame. Website descriptions retain those limits.
